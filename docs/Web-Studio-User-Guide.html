1. What this product does

Web Studio is a website builder. You create a project, design pages on a canvas, and publish the site to a live address. You do not write code.

With Web Studio you can:

  • Start from a blank project or a template.
  • Add headers, page sections, text, images, buttons, video, forms, and footers.
  • Edit the words on the page by clicking them.
  • Move pieces around the page.
  • Check the layout on desktop, tablet, and mobile.
  • Publish the site on a Web Studio address, or connect your own domain.

2. Create an account and sign in

  1. Open the Web Studio site.
  2. Click the sign-in option.
  3. Sign in with your email and password, or choose Continue with Google.
  4. If you are new, switch to sign up, enter your name, email, and password, and create the account.
  5. If you forget the password, use Forgot password and follow the email.

After a successful sign-in you land on the Dashboard.

3. The dashboard

The dashboard lists your projects. From here you create a site, open one, search, filter, or delete a project.

  1. Read the greeting at the top. It confirms you are signed in.
  2. Use the search box to find a project by name.
  3. Use the filter to show all projects, or only one status.
  4. Use sort to order projects by recent activity or by name.
  5. Click a project card to open it in the editor.

Delete a project

  1. On the project card, choose delete.
  2. Confirm the name in the dialog.
  3. The project is removed from your list.
Screenshot 6 — Delete confirmation Show the dialog that asks you to confirm deletion.

4. Create a project

  1. On the dashboard, click New Project.
  2. Type a project name. The name can be up to 100 characters.
  3. Choose Blank to start empty, or choose a template.
  4. Click the create button.
  5. Web Studio opens the editor for that project.
Screenshot 7 — New Project dialog Show the name field and the template choices, including Blank.

6. Add sections and elements

  1. Click Elements on the left.
  2. Scroll the list, or type in the search box.
  3. Click an item to drop it onto the page, or drag it onto the canvas.

The catalog is grouped like this:

GroupWhat you can add
ElementsHeading, text, paragraph, image, button, icon, video, divider, form, PDF, HTML, gallery, social
LayoutContainer
HeaderSimple, Classic, Centered, and Split headers
Hero, Features, About, and moreReady-made page sections such as Hero, Features, About, Services, Testimonials, Pricing, FAQ, Team, Gallery, Call to action, Contact, Stats, Logo cloud, and Blog list
FooterStandard footer, Minimal bar, Centered stack, Newsletter, Contact row, Mega columns, and Card band

Clicking a header replaces the current header. Clicking a footer replaces the current footer. Other sections are added to the page.

7. Edit text

  1. Click any text on the canvas. A formatting bar appears above the text.
  2. Use the bar to change bold, italic, font, size, and color.
  3. Double-click the text to type. Change the words, then click away to finish.
  4. Click an empty area of the canvas to hide the formatting bar.

The same steps work for headings, paragraphs, button labels, header links, and footer text.

8. Images

  1. Add an Image from Elements, or select an image that is already on the page.
  2. Open the properties panel on the right.
  3. Paste an image address, or choose an image from Assets.
  4. Drag the image to move it. Drag a corner to resize it.
Screenshot 14 — Selected image and properties Show the image selected and the image address field on the right.

9. Buttons and links

  1. Add a Button, or select a button that is already on the page.
  2. Double-click the label to change the words.
  3. In the properties panel, set the link. Use a page path such as /about, or a full web address.

Header and footer links have a shortcut:

  1. Hover the link.
  2. Click the arrow that appears above it.
  3. If that page already exists, Web Studio opens it.
  4. If it does not exist, a dialog asks whether to create the page. Confirm to add an empty page and open it.

10. Video

  1. Add a Video from Elements.
  2. In properties, paste a YouTube address or a video file address.
  3. To play or pause, click the center of the video.
  4. To select and move the video, click and drag the area around the center, not the center itself.
Screenshot 18 — Video on the canvas Show a video block. If you can, show it playing.

11. Header

  1. Open Elements and choose a header: Simple, Classic, Centered, or Split.
  2. The new header replaces the one on the page.
  3. Click the logo text or a menu label and type the new words.
  4. Drag a header piece if you want to adjust its place.
  5. Use the arrow on a menu item to open or create the linked page.
Screenshot 19 — Header styles Show the four header cards in the Elements panel.
Screenshot 20 — Header on the page Show the logo, menu, and button after editing.

12. Footer

  1. Open Elements and choose a footer.
  2. The new footer replaces the current footer.
  3. Click any text in the footer to edit it: logo, description, column titles, links, contact lines, and copyright.
  4. Drag a footer piece to move it.
  5. Hover a footer link or the subscribe button and use the arrow the same way as in the header.

Footer choices:

  • Footer — columns of links, social icons, and copyright.
  • Minimal bar — logo, a short row of links, and copyright.
  • Centered stack — brand, links, and social icons centered.
  • Newsletter — a subscribe line plus link columns.
  • Contact row — email, phone, and address.
  • Mega columns — brand row and four link groups.
  • Card band — a dark card on a light page.

13. Move and resize

  1. Click an item to select it. A frame appears around it.
  2. Drag the item to a new place.
  3. Drag a handle on the frame to change the width or height.
  4. Use the properties panel for an exact size, color, spacing, or alignment.
  5. Click Undo in the top bar if the move is wrong. Click Redo to put it back.
Screenshot 23 — Selected element Show the selection frame and resize handles.

14. Pages

  1. Click Pages on the left.
  2. Click a page name to open it on the canvas. The current page is highlighted.
  3. Click the plus button to add a page. Type a title such as Services or Our Story, then click Create Page.
  4. New pages use the same header and footer as the rest of the site.
  5. Open the menu on a page (the three dots) to set it active, set it as the home page, rename it, or duplicate it.
  6. Delete is available for every page except the home page. The home page address stays /.

15. Desktop, tablet, and mobile

  1. In the top bar, click the monitor icon for desktop, the tablet icon for tablet, or the phone icon for mobile.
  2. The canvas changes to that screen width.
  3. Adjust position and size while that icon is selected. Those adjustments are kept for that screen size.
  4. Switch back to desktop to confirm the wide layout is unchanged.
  5. Use the minus and plus buttons to zoom. Click the percentage to return to 100%. Click Fit to fit the page in the window.

Check all three sizes before you publish.

16. Layers

  1. Click Layers on the left.
  2. The list shows the structure of the current page.
  3. Click a name in the list to select that item on the canvas.
Screenshot 30 — Layers panel Show the outline of a page that has a few sections.

17. Assets

  1. Click Assets on the left.
  2. Upload your own image or video, or browse stock photos.
  3. Open an asset and copy its address, or use it on the selected image.
  4. You can delete assets that belong to your project. Shared library items stay in the library.
Screenshot 31 — Assets panel Show uploaded images or the stock photo browser.

18. Design

  1. Click Design on the left, or the palette icon in the top bar.
  2. Choose a color palette. The choice applies across the pages of the project.
  3. Choose a style preset if you want rounder corners, sharper corners, or a different shadow.
Screenshot 32 — Design panel Show the color palettes.

19. Preview

  1. Click the eye icon in the top bar.
  2. The editing frames hide so you can read the page as a visitor would.
  3. Click the eye icon again to return to editing.

Preview is not the live site. Visitors see the site only after you publish.

Screenshot 33 — Preview mode Show the page with the eye icon active and the side panels hidden.

20. Version history

  1. Click History on the left.
  2. Review the saved versions.
  3. Choose Restore on an older version if you need to go back.
  4. Confirm before you restore. Restoring replaces the pages with that saved copy.
Screenshot 34 — Version history Show at least one saved version and the restore action. If the list is empty, capture the empty state and note that versions appear after saves.

21. Site settings

  1. Open Site Settings from the editor.
  2. Change the project name if needed, then save.
  3. To use your own domain, type the domain, such as mysite.com, and click Connect.
  4. Copy the DNS records shown on screen and add them at the company where you bought the domain.
  5. Return to Web Studio and verify the domain. It stays pending until the DNS records are active.
Screenshot 35 — Site settings Show the project name and the custom domain field.
Screenshot 36 — DNS records Show the records the user must copy. Hide any private account details.

22. Publish the site

  1. Review the page on desktop, tablet, and mobile.
  2. Click Publish Site in the top bar.
  3. On Publish Settings, type a subdomain. The live address will look like your-name followed by the Web Studio host.
  4. Optional: open the Domain tab and enter a custom domain.
  5. Click the publish button. Wait until the status says the website published successfully.
  6. Copy the live address, or click Visit to open it in a new tab.

You need a subdomain or a custom domain before publish is available. Publishing includes hosting and an SSL certificate on the Web Studio address.

If publishing fails, read the message in the dialog, check that the subdomain is filled in, and try again. If it still fails, contact support and include the project name.

23. Update a site that is already live

  1. Open the project from the dashboard.
  2. Change the pages.
  3. Wait until the save status in the top bar is settled.
  4. Click Publish Site again.
  5. Visit the live address and refresh the page to confirm the new version.

Changes in the editor are not public until you publish again.

24. Your profile

  1. Open your profile from the dashboard.
  2. Update your name and save.
  3. The email address is shown but cannot be changed on this screen.
  4. Use Log out when you are finished on a shared computer.
Screenshot 41 — Profile Show the name field and the disabled email field.

25. A short path from zero to a live site

  1. Sign in.
  2. Click New Project, name it, and choose Blank or a template.
  3. Add a header, a hero section, and a footer.
  4. Click the text and replace the sample words with your own.
  5. Add the other pages you need, and point the menu links at them.
  6. Check desktop, tablet, and mobile.
  7. Click Publish Site, set the subdomain, and publish.
  8. Open the live address and confirm the pages.
