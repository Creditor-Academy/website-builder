## Web Studio User Guide

Step-by-step guide for the launched product

Document Status: Draft for product owners

Date: September 2026

## 1. What This Product Does

Web Studio is a no-code website builder. You create a project, design pages on a visual canvas, and publish the site directly to a live web address without writing code.

## With Web Studio, you can:

- Start from a blank canvas or choose from a library of pre-designed templates.

- Add structural components including headers, page sections, text, images, buttons, video, forms, and footers.

- Edit page copy directly inline by clicking on text elements.

- Reorder and reposition layout elements visually.

- Preview and adjust responsive layouts for desktop, tablet, and mobile views.

- Publish directly to a Web Studio subdomain or connect your own custom domain.


## 2. Create an Account and Sign In

- 1. Open the Web Studio website.

- 2. Click the Sign In option in the top navigation.

- 3. Sign in using your email and password, or select Continue with Google.

- 4. If you are a new user, switch to Sign Up, enter your name, email, and password, and create your account.

- 5. If you forget your password, click Forgot password and follow the email restoration steps.

After successful authentication, you will automatically land on the Dashboard.


## 3. The Dashboard

The dashboard serves as your central project hub. From here, you can create new sites, manage existing projects, search, filter, or delete unwanted sites.

- 1. Review the greeting bar at the top confirming your signed-in profile.

- 2. Use the Search box to quickly locate projects by title.

- 3. Use the status Filter to toggle between all projects or specific publication states.

- 4. Use the Sort dropdown to arrange projects by recent activity or alphabetical order.

- 5. Click directly on any project card to open it inside the editor.


## Delete a Project

- 1. Hover over the target project card and select Delete.

- 2. Confirm the project name in the verification dialog.

- 3. The project will be permanently removed from your account dashboard.


## 4. Create a Project

- 1. On the dashboard, click the New Project button.

- 2. Enter a descriptive project name (up to 100 characters).

- 3. Select Blank to start from scratch, or choose a pre-built template.

- 4. Click Create Project.

- 5. Web Studio will automatically launch the canvas editor for your new site.

- 1. Click Elements on the left icon rail.

- 2. Browse through the categorized library or search for specific components.

- 3. Click an item to insert it directly, or drag and drop it onto the canvas.

## 7. Edit Text

- 1. Click any text component on the canvas to expose the contextual floating format bar.

- 2. Adjust typography properties such as Bold, Italic, Font Family, Size, and Color directly.

- 3. Double-click inside the text boundary to enter direct inline editing mode.

- 4. Click anywhere outside the text element to commit changes and dismiss the formatting bar.


## 8. Images

- 1. Add an Image element from the panel, or click an existing image on the canvas.

- 2. Open the Properties panel on the right sidebar.

- 3. Insert a direct image URL, or click to choose from your project Assets.

- 4. Click and drag the image frame to reposition; drag border handles to scale dimensions.


## 9. Buttons and Links

- 1. Insert a Button element, or click an existing button.

- 2. Double-click the button label to update button text inline.

- 3. In the right Properties panel, assign a target link path (e.g., relative /about or absolute https://...).

## Interactive Navigation Link Shortcut

- 1. Hover over any link item inside headers or footers.

- 2. Click the directional Arrow icon that appears above the element.

- 3. If the linked page exists, the editor immediately navigates to that page canvas.

- 4. If the page does not exist, a dialog prompts you to auto-create and navigate to the new page.


## 10. Video

- 1. Insert a Video component from the Elements panel.

- 2. Open Properties and paste a supported YouTube URL or raw HTML5 video file link.

- 3. Click the center play icon to test playback inside the canvas.

- 4. To drag and reposition the video block, click and drag the outer frame area rather than the center control.


## 11. Header Management

- 1. Open Elements and browse to the Header section. Choose from Simple, Classic, Centered, or Split styles.

- 2. Selecting a header automatically replaces any existing top header navigation.

- 3. Click logo text or navigation items to customize text and links inline.

- 4. Drag components within the header container to customize layout spacing.

- 5. Use link shortcut arrows on menu items to link or build destination pages.

## 12. Footer Management

- 1. Open Elements and select your preferred Footer layout preset.

- 2. Selecting a new footer replaces the existing active footer component.

- 3. Double-click footer text to edit content: brand bio, link columns, contact info, and copyright tags.

- 4. Hover links or subscription form buttons to utilize quick-link shortcuts.

## Available Footer Presets

- Standard Footer: Multi-column links, social media icons, and copyright bar.

- Minimal Bar: Clean single-line layout with logo, inline links, and legal notice.

- Centered Stack: Stacked layout with centered logo, link row, and social channels.

- Newsletter: Integrated email subscription bar alongside category link columns.

- Contact Row: Focuses on direct contact details (Email, Phone, Physical Address).


- Mega Columns: Comprehensive layout with primary brand block and four sub-link columns.

- Card Band: Highlighted dark/accented card container layout.

## 13. Move and Resize Components

- 1. Click any component to activate its bounding selection frame.

- 2. Click and drag the component body to reorder layout positions.

- 3. Click and drag blue transformation handles on corners/edges to adjust height and width.

- 4. Use the Properties panel for precise numerical controls (Padding, Margin, Alignment, Hex Colors).

- 5. Click Undo (Ctrl+Z) or Redo (Ctrl+Y) in the top bar to reverse or re-apply layout edits.


## 14. Managing Pages

- 1. Click Pages on the left icon rail to open site page structure.

- 2. Click any page title to switch active working canvas.

- 3. Click + Add Page, enter a page name (e.g., Services), and click Create Page.

- 4. Newly created pages automatically inherit global site Headers and Footers.

- 5. Click the Three-Dots Menu (...) next to any page item to access settings:

- Set Active / Set as Homepage

- Rename

- Duplicate

- Delete (Available for all sub-pages; Primary Homepage / cannot be deleted).


## 15. Responsive Design (Desktop, Tablet, Mobile)

- 1. Locate device viewports in the top bar: Desktop (Monitor), Tablet, and Mobile (Phone).

- 2. Select a viewport mode to adjust canvas display width.

- 3. Make layout, spacing, or sizing tweaks while in specific viewport modes—adjustments automatically save for that screen size.

- 4. Switch back to Desktop view to confirm primary wide-screen alignment remains intact.

- 5. Use Zoom (+ / -), click percentage to reset to 100%, or click Fit to auto-scale canvas to screen space.


## 16. Layers Panel

- 1. Click Layers on the left rail to view document object tree hierarchy.

- 2. View nested structure of components, containers, and sections on the active page.

- 3. Click any element layer name to instantly select and isolate that element on the visual canvas.


## 17. Assets Manager

- 1. Click Assets on the left rail.

- 2. Upload custom media files (PNG, JPG, SVG, MP4) or search royalty-free stock image libraries.

- 3. Select an asset to copy its hosted source URL or apply it directly to selected image elements.

- 4. Delete uploaded account assets as needed (Shared global library assets remain permanent).

## 18. Global Design System

- 1. Click Design on the left rail (or click the Palette icon in the top toolbar).

- 2. Choose a primary Color Palette to enforce consistent color scheme application across all pages.

- 3. Select a Style Preset to adjust site-wide border radii, corner sharpness, and shadow depth.


## 19. Preview Mode

- 1. Click the Eye Icon in the top toolbar to toggle Preview mode.

- 2. Editing frames, grid overlays, and sidebars hide to show exact visitor rendering.

- 3. Click the Eye Icon again to return to editing mode.

Note: Preview mode is an isolated editor simulation. Your changes are not accessible to external web visitors until you execute a Publish.

## 20. Version History

- 1. Click History on the left rail.

- 2. Review automatically logged revisions with timestamps.

- 3. Click Restore on any historic revision to rollback site state.

- 4. Confirm rollback in dialog prompt. (Restoring overwrites active drafts with selected historic revision).

## 21. Site Settings & Custom Domains

- 1. Navigate to Site Settings from the main editor interface.

- 2. Update public Project Name settings as required.


- 3. To configure custom branding, enter your custom web address (e.g., mysite.com) in the Custom Domain field and click Connect.

- 4. Copy the generated DNS Records (A & CNAME) provided on screen and input them into your domain registrar (e.g., GoDaddy, Namecheap).

- 5. Return to Web Studio and click Verify Domain. Status will display Pending until DNS propagation completes.

## 22. Publishing Your Website

- 1. Perform final layout checks across Desktop, Tablet, and Mobile viewports.

- 2. Click Publish Site in the top bar.

- 3. Under Publish Settings, enter a unique Subdomain. Your default live URL will be your-subdomain.webstudio.site.

- 4. (Optional) Switch to the Domain tab to assign your verified custom domain.

- 5. Click Publish Now. Wait for build execution until success message displays.

- 6. Copy the generated live link, or click Visit Site to launch in a new tab.

Requirements: Sites require either an assigned free subdomain or connected custom domain prior to publishing. Standard publishing includes automated SSL certificate generation and cloud hosting deployment.

## 23. Updating a Live Site

- 1. Access your project from the Web Studio Dashboard.

- 2. Perform required visual or copy modifications on the canvas.

- 3. Ensure top bar save indicator displays green status.

- 4. Click Publish Site again to push changes to production.

- 5. Refresh live web browser tab to verify deployed updates.

## 24. Profile Management

- 1. Click your user avatar on the main dashboard and choose Profile.

- 2. Modify user display name settings and click Save.

- 3. View registered account email address (Email field is read-only).


- 4. Click Log Out when ending session on shared or public devices.

## 25. Quickstart Summary: Zero to Live in 8 Steps

- 1. Sign In: Access your Web Studio account.

- 2. Create: Click New Project, title your site, and choose a starting template or blank canvas.

- 3. Structure: Add Header, Hero, Body Content, and Footer blocks from the Elements rail.

- 4. Content: Double-click default text blocks and swap images to insert custom branding.

- 5. Pages: Add required secondary pages (e.g., About, Contact) and link menu items.

- 6. Responsiveness: Toggle Desktop, Tablet, and Mobile views to verify fluid layout rendering.

- 7. Publish: Click Publish Site, configure your preferred subdomain, and hit Deploy.

- 8. Verify: Open live URL to view your newly published site.
